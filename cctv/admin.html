Orders

Orders isn't wired up yet

This needs a real payment processor (Stripe is the natural fit for USD/global card payments) plus webhook-driven Cloud Functions to write order docs, update stock, and generate invoices. It's a separate integration from the storefront/admin CRUD built so far.

  • Payment provider webhook → Cloud Function
  • Order status, tracking, refunds
  • Invoice generation
